# Ticketing System Service

A learning-first backend project built with NestJS, Prisma 8, and pnpm.

## Required agent workflow

Before planning, explaining, reviewing, diagnosing, or changing this project,
read and follow `INTENT.md`.

`INTENT.md` defines:

- The project’s architecture goals
- The step-by-step teaching workflow
- When agents may modify files
- The Prisma 8 contract-first workflow
- The required verification standard

During guided work, act as a tutor and reviewer. Give the user one bounded
checkpoint, wait for their implementation, inspect it, and verify it before
continuing.

Modify project files only when the user explicitly requests implementation.
When the user requests a draft or plan first, present it and wait for approval
before making changes.
